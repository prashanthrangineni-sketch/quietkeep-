## Summary

Implements **AG-03: Anomaly watcher v1, report-only (architecture step 8)**.
Adds real-time, report-only anomaly scorers to QuietKeep's drive safety engine to detect trip divergences, street-theft phone snatches, and prolonged late-night stops.

### What Was Built
1. **Pure Scorers & Stateful Watcher (`src/lib/anomaly-watch.js`)**:
   - `routeDeviation({ destination, fixes, origin })`: Computes cross-track distance from straight-line corridor and distance to destination. Triggers `watch` when distance from corridor grows for $\ge 3$ minutes while moving away from destination; triggers `high` when sustained for $\ge 6$ minutes.
   - `phoneSnatch({ motion, speedKmh, speedBeforeKmh, now })`: Detects sharp acceleration jerk ($> 2.5\text{ g}$ for $< 300\text{ ms}$) while pedestrian/stationary ($< 8\text{ km/h}$), followed by running pace ($8\text{–}20\text{ km/h}$) within $20\text{ seconds}$. Triggers `watch` (never `high` in v1).
   - `longUnexpectedStop({ fixes, now, knownStops })`: Detects stationary vehicle ($> 10\text{ minutes}$) during an active ride at night ($23:00\text{–}05:00$) in an unvisited location (not in `knownStops`). Triggers `watch`.
   - `createAnomalyWatcher({ destination, knownStops, clock, onAnomaly })`: In-memory stateful watcher with bounded ring buffer (20 items), deduplicating transitions and dispatching `onAnomaly` callbacks.
2. **Ride Guard Wire-in (`src/lib/ride-guard.js`)**:
   - Wired `createAnomalyWatcher` into `startRideGuard` lifecycle.
   - Connected `onMotion` acceleration magnitude feed.
   - Connected `feedSpeed` GPS fixes and speed updates.
   - Dispatches `onState?.('anomaly', { kind, level, reasons })`.
   - Exposed `guard.getAnomalies()` and `guard.setDestination()`.
   - **Strictly report-only: zero spoken talkback lines, zero calls/messages, and zero SOS alerts.**
3. **Unit Test Suite (`tests/anomaly-watch.test.mjs`)**:
   - 3 scripted firing scenarios per scorer (9 test scenarios).
   - False-alarm guard: 30-minute realistic commute with traffic signals, tea stop, and a U-turn producing 0 false alarms.
   - Night boundary tests with injected clock ($22:59\rightarrow\text{none}, 23:01\rightarrow\text{watch}, 04:59\rightarrow\text{watch}, 05:01\rightarrow\text{none}$).
   - Phone snatch parameter bounds (pre-speed, post-speed, jerk duration, magnitude, 20s window, and max level watch).
   - Full watcher integration and reset lifecycle.
   - 51 passed, 0 failed.
4. **Documentation (`docs/anomaly-watch-v1.md`)**:
   - Detailed specification of all 3 anomaly rules, math, thresholds, and rationales.
   - Sensor boundaries and what the watcher cannot know (no camera, no turn-by-turn routing graph yet, no microphone listening).
   - Report-only architecture principles.

### Safety Limits & Rules
- **Report-only:** Never calls, never messages, never alerts family, never initiates SOS.
- **Nothing spoken in v1:** Zero voice prompts or audio interruptions.
- **No external network calls, no AI/LLM calls, no new npm dependencies, no microphone use, no camera use.**
- Only allowed files modified.
