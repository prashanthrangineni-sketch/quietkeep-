## Summary

Implements **AG-02: Hybrid and two-wheeler profiles on the simulated car (DRV-07a)**.
Expands the QuietKeep Car Reader OBD-II telemetry suite to support multiple vehicle profiles, including Honda and Toyota full hybrids (City e:HEV, Hyryder/Hycross), BS-6 two-wheelers (motorcycles/scooters), diesel cars, and petrol cars.

### What Was Built
1. **Mode 01 Standard Decoders (`src/lib/obd/pids.js`)**:
   - `5B`: Hybrid battery pack remaining life (`(A * 100) / 255` %).
   - `51`: Fuel type table per SAE J1979 (1 petrol, 4 diesel, 8 electric, 0x11 hybrid petrol, etc.).
   - `46`: Ambient air temperature (`A - 40` °C).
   - `5C`: Engine oil temperature (`A - 40` °C).
   - `11`: Throttle position (`(A * 100) / 255` %).
   - Decoders added to `MODE_01_DECODERS` and automatically decoded in `decodeMode01Response()`.
2. **Vehicle Profiles Engine (`src/lib/obd/profiles.js`)**:
   - Profiles: `petrol_car`, `diesel_car`, `honda_hybrid`, `toyota_hybrid`, `bs6_two_wheeler`.
   - `detectProfile(supportedPids, fuelType, options)`: Pure detection from supported PID bitmaps, fuel type representation, and optional VIN/make metadata.
   - `isEngineOffNormal(profile, speedKmh, rpm)`: Recognizes that in hybrids (City e:HEV, Hyryder), EV mode at low/moderate speed (0 RPM while moving) is completely normal and must never be flagged as an engine stall.
   - `summaryFor(profile, snapshot, faults, lang)`: Profile-tailored voice summary with full multilingual support in English, Hindi, and Telugu:
     - Hybrids: Voice summary explicitly includes `"Hybrid battery at N percent"`.
     - Two-wheelers: Kept short and concise for riders (e.g. `"Battery 12.8 volts, no warning lights."`), treating small 12–13.5 V batteries as healthy.
     - Non-hybrids: Warns if engine is stalled while moving.
3. **Simulated Vehicle Profiles (`src/lib/obd/simulator.js`)**:
   - Added `profile` constructor option with realistic behaviors per profile:
     - `honda_hybrid`: Fuel type 0x11, VIN prefix `MAK` (Honda India), supported PID 5B, EV mode (0 RPM while moving at speed <= 40 km/h or `engineOffWhileMoving: true`), ~78% hybrid battery.
     - `toyota_hybrid`: Fuel type 0x11, VIN prefix `MBJ` (Toyota India), supported PID 5B, EV mode (0 RPM while moving), ~82% hybrid battery.
     - `bs6_two_wheeler`: Minimal PID bitmap (only 01, 05, 0C, 0D, 11; no load 04, no fuel 2F), 12.8 V small battery voltage on both 0142 and ATRV.
     - `diesel_car`: Fuel type 0x04, compression ignition indicator, oil temp 015C telemetry.
     - `petrol_car`: Standard ICE baseline behavior.
4. **Car Reader API (`src/lib/obd/reader.js`)**:
   - `readSnapshot()` returns extended fields (`throttlePct`, `ambientTempC`, `oilTempC`, `fuelType`, `hybridBatteryPct`) when supported.
   - `detectProfile()` auto-detects profile from ECU telemetry and caches it.
   - `summary()` delegates to `summaryFor` when a profile is detected or configured.
   - Fixed `fuelPct` assignment typo.
5. **Unit Test Suites**:
   - `tests/obd.test.mjs`: Added tests for new decoders (11, 46, 51, 5B, 5C); all 82 tests pass.
   - `tests/obd-profiles.test.mjs`: Dedicated test suite verifying decoder math with known byte fixtures, profile detection across all 5 profiles, the hybrid EV mode normalcy rule, two-wheeler concise summary and voltage threshold, and full simulated sessions per profile (67 tests pass).
6. **Documentation (`docs/obd-v1.md`)**:
   - Documented the 5 vehicle profiles, new mode 01 PIDs, simulator configuration, and reader profile integration.

### Safety Limits & Wording
- `src/lib/obd/elm327.js` was **NOT touched** — strict read-only allow-list remains intact.
- Mode 04 (clear codes) and EEPROM write AT commands remain permanently blocked.
- No network calls, AI/LLM calls, microphone, or camera access.
- Read-only diagnostics by design.
