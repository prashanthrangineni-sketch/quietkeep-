## Summary

Implements **AG-06: Ride notes on the Drive Mode screen (display only)**.
During and after a ride the driver sees in plain words what the guard noticed:
- Overtaking warnings
- Indicator reminders
- Fatigue level changes
- Hazard warnings
- Report-only anomaly notes

Nothing is spoken, sent, uploaded or stored outside memory.

### What Was Built

1. **`src/lib/ride-notes.js`**:
   - `createRideNotes({ max = 20, clock })`: Pure in-memory collection with injectable clock.
     - Keeps only the five allowed kinds: `overtake`, `indicator`, `fatigue`, `hazard_warning`, `anomaly`.
     - Stores `{ kind, at, text }`, newest first, up to `max` items (default 20).
     - Methods: `add(state, detail)`, `list()`, `clear()`.
     - `noteText(kind, detail)`:
       - `overtake` -> The phrase spoken (e.g. from `phrase`, `text`, `spoken`), or safe generic fallback.
       - `indicator` -> The phrase (e.g. from `phrase`, `text`), or safe generic fallback.
       - `fatigue` -> `"Tiredness check: you sounded <level>"` (e.g. `drowsy`, `watch`, `alert`), or `"Tiredness check"`.
       - `hazard_warning` -> The warning text if present, else `"Hazard warning ahead"`.
       - `anomaly` -> `"Noted (not reported to anyone): <kind in plain words> — <level>"` (e.g. `route deviation — watch`, `phone snatch — high`, `unexpected stop — watch`).
       - Missing or odd detail never throws (safe generic fallbacks).
       - Never includes coordinates or personal data; numbers with 4+ decimal places are sanitized to prevent GPS coordinate leakage.

2. **`src/app/drive/page.jsx`**:
   - `rideNotesRef`: Ref holding the notes collection instance created when Drive Mode starts (cleared at the next start, kept after exit so notes remain visible after a ride).
   - `startRideGuard` `onState` callback: Calls `rideNotesRef.current.add(state, detail)` and updates `rideNotes` state list.
   - "Ride notes" card placed near "Last records":
     - Local time `hh:mm` + text for each item.
     - Empty state displays `"Nothing noted on this ride."`.
     - Matches the page's existing card styling (`var(--card-bg)`, `var(--border)`, dark mode accents).
     - Nothing else changes.

3. **`tests/ride-notes.test.mjs`**:
   - Plain node test suite verifying:
     - Each kind's text extraction and formatting.
     - Unknown kinds ignored (returns null, not added to list).
     - Max cap and newest-first order.
     - Odd/missing detail resilience (null, undefined, primitives, circular references never throw).
     - `clear()` behavior.
     - Decimal precision guard: verifies no note text contains a number with 4+ decimal places (`/\d+\.\d{4,}/`).
